Python学习（一）：程序设计基本方法

发表于2026-09-27|更新于2026-10-21|Python
|浏览量:

学任何一门语言都绕不开开头的概念课：它是谁发明的、凭什么流行、代码怎么写才算规范。这篇把 Python 的「身份证」和「基本法」一次理清：语言特性、编译与解释、注释与命名、保留字、数据类型，最后是程序编写的基本框架 IPO。

Python 是一门什么样的语言

Python 由荷兰人 Guido van Rossum 创立。它是目前最受欢迎的编程语言之一，五个标签可以概括它的身份：

  • 通用语言：能写脚本、爬虫、Web、数据分析、人工智能，几乎无处不在；
  • 解释性语言：代码由解释器逐句执行，不用编译成二进制，写完就能跑；
  • 开源语言：源码开放，任何人都可以参与和贡献；
  • 跨平台语言：同一份代码可以在 Windows、Linux、macOS 上运行；
  • 多范式语言：面向过程、面向对象、函数式，想用哪种风格都行。

为什么选 Python

两条主线：语法简洁和生态高产。

语法层面，完成同样功能 Python 的代码量大约只有 C 语言的 10%，语法强制可读性（缩进即语法），底层语法元素少，支持多种编程方式，还直接支持中文字符。

生态层面，PyPI 上有超过 50 万个第三方库，计算生态增长极快——大多数问题别人已经写好了轮子，import 一下就能用。开放共享、跨操作系统平台，让”避免重复造轮子”成了 Python 社区的默认文化。

编译和解释

按执行方式，编程语言分两大类：

  • 静态语言（编译型，如 C/C++）：源代码先经编译器一次性翻译成目标代码，之后执行的都是目标代码，速度快；
  • 脚本语言（解释型，如 Python）：源代码由解释器逐句翻译并立即执行，每次运行都要重新解释，但天然跨平台、灵活。

注释的写法

Python 用 # 开头写单行注释；需要成段的说明文字时，用三引号包裹多行注释。注释不参与程序执行，是写给”未来的自己和其他人”看的：

命名规则

给变量、函数起名字，可以用大小写字母、数字、下划线和中文等字符及组合，但有三条红线：

  1. 大小写敏感——name 和 Name 是两个不同的名字；
  2. 首字符不能是数字；
  3. 不能与保留字相同。

保留字（关键字）

Python 有 35 个保留字，它们是语言的基本单词，被语法本身占用，不能拿来当变量名。同样因为大小写敏感，if 是保留字，而 If 只是一个普通变量名——这个例子最能说明保留字规则：

数据类型

同一串数字 10,011,101，套上不同的”外壳”就是完全不同的类型：

写法 类型 含义
10011101 整数 一个普通整数
"10,011,101" 字符串 一串文本字符
[10, 011, 101] 列表 一组有序元素

程序怎么理解一串数据，取决于你给它什么类型——这是强类型语言的基石。

程序的基本编写方法（IPO）

再复杂的程序，都可以拆成三段式结构，这就是 IPO 模型：

  • 输入（Input）：程序的开端。可以来自交互输入（input()）、文件、网络，也可以是程序参数；
  • 处理（Process）：程序的核心，也就是算法——把输入加工成输出的一步步逻辑；
  • 输出（Output）：程序展示成果的方式，打印到控制台、写文件、显示图形界面都算。

写程序前先想清楚”输入是什么、输出要什么、中间怎么算”，思路会比直接动手敲代码清晰得多。

这一篇是整个 Python 系列的地基：35 个保留字是语法的”单词表”，IPO 是程序的”句型”。下一篇开始动手写代码，这些概念会反复出现。
