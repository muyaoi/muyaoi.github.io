防火墙学习（二）：通过业务口 Web 登录防火墙

发表于2026-09-27|更新于2026-09-27|防火墙
|浏览量:

上一篇能登进 Web 界面，靠的是出厂就配好 IP、铺好路的管理口 GE0/0/0。但实际组网里，防火墙往往装在机柜里，管理口未必接在你手边——更常用的做法是让业务口也具备管理能力。这篇就完整走一遍「接口 IP → 服务放行 → 区域划分 → 账号权限」四个环节，比第一篇多出了区域和账号两块拼图。

实验拓扑

还是防火墙加 Cloud 云的组合，变化在网段：这次桥接的网卡在 10.1.2.x 网段，准备把业务口 GE1/0/0 配成 10.1.2.1，真实主机当 Web 客户端：

配置 Cloud 云

打开 Cloud 配置，添加 UDP 和真实网卡（10.1.2.100 所在的 eNSP 网卡）并设置端口，开启双向通道。原理和上一篇完全一样，只是换了个网段接入：

Console 首次登录并改密

开启防火墙设备，输入默认用户 admin、密码 Admin@123，首次登录会强制修改密码，这里改为 huawei@123。这一步和上一篇相同，是所有后续配置的入口：

配置业务口 GE1/0/0

业务口和管理口最大的区别：出厂既没有 IP，也不在任何安全区域里。所以要从头配起。先进入 GE1/0/0：

老规矩，先开服务管理功能，再放行 HTTP 和 HTTPS——这层「接口服务开关」和管理口上的配置是一样的：

接着给接口配上 IP 地址并退出接口视图：

将接口加入 Trust 区域

这一步是业务口和管理口的本质差异：防火墙只检查「区域之间」的流量，接口必须先划入某个安全区域，才有资格参与安全策略的检查。进入受信任区域（trust），把 GE1/0/0 加进去：

trust 是受信任区域，优先级仅次于防火墙本机（local）。把我们自己的管理流量从 trust 区域发往防火墙自身，方向就是 trust → local。

配置 VTY 登录与 AAA 账号

Web 界面之外，先把命令行的远程登录底座打好。进入 VTY 视图（虚拟终端），0 4 表示 0 到 4 共 5 路，也就是允许 5 个用户同时远程登录：

把登录用户的等级设为 3 级。华为设备的命令行等级从 0 到 3（访问级、监控级、配置级、管理级），3 级是最高级，能进系统视图做全部配置：

然后进入 AAA 认证视图，创建登录账号：用户名 whx、密码 whx@123456、等级 3 级。AAA 负责三件事——认证（Authentication，你是谁）、授权（Authorization，你能干什么）、审计（Accounting，你干过什么）：

创建好的用户还要开启 Web 登录服务，再添加到系统用户里，赋予管理员角色——否则账号虽然存在，却没有登录 Web 界面的权限：

浏览器登录验证

在浏览器地址栏输入 https://10.1.2.1:8443，这次用刚创建的 whx 账号登录：

对比两篇的差异就是业务口管理的完整清单：接口 IP、service-manage 服务放行、划入安全区域、AAA 账号授权。管理口出厂替你做好了后两项，业务口则要自己动手——少任何一步，Web 页面都打不开。
